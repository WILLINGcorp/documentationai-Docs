## Overview

MB Events lets you list, promote, and manage industry events on ModelBoard so attendees can discover events, reserve a spot, and stay connected before and during the event.

<Callout kind="info" collapsed="false">

Any logged-in ModelBoard user can browse event pages and register for events. Business, Studio, and Enterprise accounts can create and organize events.

</Callout>

Use MB Events for small meetups, paid workshops, virtual webinars, hybrid launches, and larger convention-style events. Each event includes a dedicated detail page with registration, attendee visibility, and group chat in one place.

## Who can attend and who can create

<Tabs>
  <Tab title="All logged-in users" icon="users">

  Logged-in ModelBoard users can view event pages, open event details, and register for available events.

  Event pages were previously limited to admins. Event access is now available to every authenticated user.

  </Tab>
  <Tab title="Business, Studio, and Enterprise" icon="briefcase">

  Business, Studio, and Enterprise accounts can create and organize events in addition to attending them.

  Organizers can publish events, update event details after publishing, create chat rooms, and monitor attendee activity.

  </Tab>
  <Tab title="Model accounts" icon="user">

  Model accounts can attend events, browse attendee lists where available, and join event chat rooms after registering.

  If you need to host events for your organization, use a Business, Studio, or Enterprise account.

  </Tab>
</Tabs>

## Create an event

Create events with a four-step Event Creation Wizard that walks you from basic details to publishing.

<Callout kind="alert" collapsed="false">

You can edit most event details after publishing, so focus on getting the essential information right before you make the event visible.

</Callout>

<Steps>
  <Step title="Add Event Type and Info" icon="edit" title-type="p">

  Start with the core details attendees need to recognize and trust the event.

  - Enter an **Event Title**. This field is required.
  - Choose an **Event Category**. This field is required.
  - Add a **Description** to explain the event, agenda, or audience.
  - Add **Tags** to improve discovery and context.
  - Add an **Event Website** if you want attendees to visit an official page.

  Choose one of these Event Category options:

  - `meetup`
  - `content_launch`
  - `masterclass`
  - `convention`
  - `workshop`
  - `networking`
  - `conference`
  - `webinar`
  - `premiere`
  - `fan_meet`

  When this step is complete, you have enough information for attendees to understand what the event is and why they should care.

  </Step>

  <Step title="Set Schedule and Location" icon="calendar" title-type="p">

  Add the date, time, and location details that determine when and where people attend.

  - Set the **Start Date**. This field is required.
  - Set the **Start Time**. This field is required.
  - Optionally add an **End Date** and **End Time**.
  - Choose a **Location Type**: **Physical**, **Virtual**, or **Hybrid**.

  The fields you complete next depend on the location type:

  - **Physical** — add **Venue Name** and **Address**
  - **Virtual** — choose a platform and add a meeting link
  - **Hybrid** — add both in-person and virtual details

  For virtual and hybrid events, choose one platform option:

  - `Zoom`
  - `Teams`
  - `Meet`
  - `Discord`
  - `Custom`

  Add the meeting link carefully so attendees land in the right place on event day.

  </Step>

  <Step title="Configure Access and Ticketing" icon="lock" title-type="p">

  Control who can see the event, how many people can attend, and how registration works.

  - Choose **Event Visibility**:
    - `Public`
    - `Members Only`
    - `Invite Only`
    - `Private`
  - Set **Max Attendees** if you want to cap capacity.
  - Turn on **Require Approval** if you want to manually review registrations.
  - Choose **Ticket Type**: `Free` or `Paid`
  - If you choose `Paid`, enter the ticket price in USD.
  - Optionally add an **External Registration URL**

  This step determines whether ModelBoard handles registration directly or sends attendees to another registration page.

  </Step>

  <Step title="Review and publish" icon="check-circle" title-type="p">

  Review the event summary before publishing. Check the title, schedule, location, visibility, and ticketing details for accuracy.

  Publish the event when everything looks right. After publishing, the event becomes visible according to the visibility setting you selected.

  </Step>
</Steps>

## Use an external registration page

Add an **External Registration URL** when you want the event page to send attendees to a third-party registration or ticketing system.

<Callout kind="tip" collapsed="false">

When an External Registration URL is set, the **Reserve Your Spot** button opens that external page in a new tab instead of registering the attendee through ModelBoard. If someone is already registered, the button shows **You're registered** even when an external URL is configured.

</Callout>

Use this option when ticketing, approvals, payment collection, or capacity control happens outside ModelBoard. Keep the event detail page updated so attendees still have one reliable place to find event details, sponsors, location information, and chat.

## Use the event detail page

Each event includes a detail page that brings event information, registration, attendees, and chat together.

### Overview tab

The **Overview** tab helps attendees decide whether to register and gives them the details they need before the event.

It includes the event description, sponsor information grouped by tier, venue details when provided, and a registration card. The registration card shows the ticket price, current capacity information, and the **Reserve Your Spot** button.

### Attendees tab

The **Attendees** tab shows a searchable grid of confirmed attendees with profile avatars and ticket type badges.

Organizers get more visibility here than attendees do. They can also see attendee check-in status, which helps with day-of-event coordination.

### Group Chat tab

The **Group Chat** tab gives attendees and organizers a place to communicate in real time.

Organizers can create chat rooms for announcements, topics, or networking. Attendees join a room to start chatting, which makes it easier to keep conversations organized during multi-session or multi-track events.

## Register for an event

Reserve your spot from the event detail page.

<Steps>
  <Step title="Open the event detail page" icon="calendar" title-type="p">

  Sign in to ModelBoard, browse to the event you want to attend, and open the full event page.

  You should now see the event overview, attendee information, and the registration card.

  </Step>

  <Step title="Click Reserve Your Spot" icon="play-circle" title-type="p">

  Select **Reserve Your Spot** in the registration card.

  What happens next depends on how the organizer configured registration:

  - If the event uses an **External Registration URL**, ModelBoard opens the external registration page in a new tab.
  - If the event uses ModelBoard registration, ModelBoard registers you directly from the event page.

  </Step>

  <Step title="Confirm your registration state" icon="check-circle" title-type="p">

  After registration succeeds, the button changes to **You're registered**.

  That button state is your confirmation that your spot has already been reserved. If you return to the event later, you can also use the Attendees and Group Chat tabs as available.

  </Step>
</Steps>

## Organizer features

If you created the event, ModelBoard shows organizer-specific controls and status indicators across the event page.

Organizers can:

- See an **Organizer** badge on the event detail page
- Create new chat rooms in **Group Chat**
- View attendee check-in status in **Attendees**
- Edit and manage the event after publishing

These controls help you keep the event page active before, during, and after the event instead of treating it as a static listing.
