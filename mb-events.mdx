## Overview

MB Events helps you host and attend industry events inside ModelBoard. Use it to publish meetups, workshops, webinars, premieres, conferences, and other event formats, then manage registration, visibility, ticketing, and attendee conversation in one place.

Event organizers can create events with a guided setup flow, choose how people register, and update or cancel events later. Attendees can discover events, view schedules and location details, reserve a spot, and join the event chat.

<Callout kind="info" collapsed="false">
  MB Events supports these event categories: Meetup, Content Launch, Masterclass, Convention, Workshop, Networking, Conference, Webinar, Premiere, and Fan Meet.
</Callout>

## Limited Beta access

MB Events is currently in Limited Beta and restricted to admin users only. If you are not an admin, the app appears in the App Store with a locked **Limited Beta — Admins only** button, and direct access redirects you back to the App Store.

<Callout kind="alert" collapsed="false">
  Admin access controls whether you can open MB Events at all. Even if your account type supports event creation, you still need admin access while the feature remains in Limited Beta.
</Callout>

## Create an event

Create an event with a four-step wizard that walks you from basic details to publishing. The flow is designed to keep the common path fast while still supporting ticketing, approval-based registration, and external registration pages.

<Callout kind="tip" collapsed="false">
  Gather your event title, start time, visibility choice, and registration plan before you begin. If you are hosting a virtual or hybrid event, keep your meeting link ready so you can publish in one pass.
</Callout>

<Steps>
  <Step title="Event Type & Info" icon="edit" title-type="p">

  - Enter an **Event Title**. This field is required.

  - Choose an **Event Category**. You can select from Meetup, Content Launch, Masterclass, Convention, Workshop, Networking, Conference, Webinar, Premiere, or Fan Meet.

  - Add an **Event Description** if you want attendees to understand the format, audience, or agenda before registering.

  - Add **Tags** as a comma-separated list to help organize the event.

  - Add an **Event Website** if you want to send attendees to an official event page.

  Success signal: the wizard lets you continue after you have entered a title and selected a category.

  </Step>

  <Step title="Schedule & Location" icon="calendar" title-type="p">

  - Set a **Start Date** and **Start Time**. Both are required.

  - Add an **End Date** and **End Time** if your event has a defined finish time.

  - Choose a **Location Type**:
    - **Physical** for in-person events
    - **Virtual** for online events
    - **Hybrid** for events with both in-person and online attendance

  - If you choose **Physical**, enter the **Venue Name** and **Address**.

  - If you choose **Virtual** or **Hybrid**, select a platform such as Zoom, Microsoft Teams, Google Meet, Discord, or Custom Platform, then add the **Meeting Link**.

  Success signal: the wizard lets you continue after you have set the start date and start time.

  </Step>

  <Step title="Access & Ticketing" icon="lock" title-type="p">

  - Choose **Event Visibility**:
    - **Public**
    - **Members Only**
    - **Invite Only**
    - **Private**

  - Set **Max Attendees** if you want to cap registration. Leave it blank for unlimited capacity.

  - Turn on **Require approval for registration** if attendees should wait for organizer approval.

  - Choose a **Ticket Type**:
    - **Free**
    - **Paid**

  - If you choose **Paid**, enter the **Ticket Price** in USD.

  - Add an **External Registration URL** if registrations happen outside ModelBoard. When this field is set, the event page sends attendees to that external page instead of registering them inside ModelBoard.

  Success signal: the wizard shows your chosen visibility, ticketing, and registration behavior in the final review step.

  </Step>

  <Step title="Review & Publish" icon="check-circle" title-type="p">

  - Review the summary card for your event title, category, schedule, location, access settings, and ticket details.

  - Confirm that the visibility setting matches how broadly you want the event to appear.

  - Select **Publish Event** to create the event.

  Success signal: the event is created and becomes visible according to the visibility rules you selected.

  </Step>
</Steps>

## Compare event formats

Different event categories suit different audiences and delivery styles. Use the examples below to choose a format that matches how you want people to participate.

<Tabs>
  <Tab title="In-person formats" icon="users">

  In-person events work best when attendance depends on physical presence, venue logistics, or face-to-face interaction.

  - **Meetup** for casual networking
  - **Convention** for larger industry gatherings
  - **Workshop** for hands-on sessions
  - **Conference** for talks, panels, or scheduled tracks
  - **Fan Meet** for creator and audience interaction

  Choose **Physical** or **Hybrid** location if attendees need venue details on the event page.

  </Tab>

  <Tab title="Online formats" icon="monitor">

  Online events work best when you want low-friction attendance across locations.

  - **Webinar** for presentations
  - **Masterclass** for guided education
  - **Content Launch** for premieres and announcements
  - **Premiere** for release events
  - **Networking** for remote industry connection

  Choose **Virtual** or **Hybrid** location so you can add a platform and meeting link.

  </Tab>

  <Tab title="Access planning" icon="settings">

  Visibility and ticketing shape how attendees discover and join your event.

  - Use **Public** when broad discovery matters.
  - Use **Members Only** when the event is intended for the ModelBoard community.
  - Use **Invite Only** when attendance should stay curated.
  - Use **Private** when you do not want the event to be discoverable.

  Pair those settings with **Free** or **Paid** tickets depending on whether registration is open access or commercial.

  </Tab>
</Tabs>

## Who can create events

Business, Studio, and Enterprise account holders can create and manage events. These account types see the event creation actions inside MB Events when they have access to the app.

Model accounts can still participate as attendees. They can discover events, open event pages, reserve a spot when registration is available, and join event chat, but they cannot create events.

<Callout kind="info" collapsed="false">
  Creation permissions and app access are separate. Your account type controls whether you can create events, while Limited Beta admin access controls whether you can open MB Events during the beta period.
</Callout>

## Explore the event detail page

Each event page brings the key details and attendee actions into one view. You can quickly confirm what the event is, who is organizing it, when it happens, where it takes place, and how to join.

The event header includes the title, description, organizer information, and quick actions such as **Add to Calendar**, **Share**, and **Favorite**. Below that, info tiles summarize the date, time, location, and current attendee count.

The event page also includes three main tabs:

- **Overview** for the event description and supporting details
- **Attendees** for participation visibility
- **Group Chat** for event conversation

In the overview layout, a registration sidebar shows the ticket price, how many spots are reserved, and the **Reserve Your Spot** button.

## Understand Reserve Your Spot behavior

The registration button changes based on how the organizer configured the event and whether you have already joined.

<ExpandableGroup>
  <Expandable title="External registration URL is set">

  If the organizer added an external registration URL and you are not already registered, **Reserve Your Spot** opens that external page in a new tab.

  Use this flow when ticketing or registration happens outside ModelBoard. Opening the external page does not create a ModelBoard registration automatically.

  </Expandable>

  <Expandable title="No external registration URL is set">

  If the organizer did not add an external registration URL and you are not already registered, selecting **Reserve Your Spot** registers you on ModelBoard.

  After registration succeeds, the page confirms that you are registered for the event.

  </Expandable>

  <Expandable title="You already registered">

  If you have already registered, the button changes to **You're registered** and becomes unavailable.

  This state prevents duplicate registration.

  </Expandable>

  <Expandable title="You are not signed in">

  If registration happens on ModelBoard and you are not signed in, you are prompted to sign in before completing registration.

  Sign in first, then return to the event page to reserve your spot.

  </Expandable>
</ExpandableGroup>

## Join the event group chat

Each event includes a **Group Chat** tab with channel-based conversation for attendees and organizers. Use it to ask questions, share updates, and keep event discussion in one place.

The left side shows available rooms, including announcement-style rooms and standard discussion channels. The organizer can create new rooms when the event needs separate spaces for updates, logistics, or topic-based discussion.

When you open a room, you join that channel automatically. After that, you can send messages directly in the chat composer. Press <kbd>Enter</kbd> to send a message, or press <kbd>Shift</kbd> + <kbd>Enter</kbd> to start a new line.

<Callout kind="tip" collapsed="false">
  If you are organizing an event, create a dedicated announcements room so attendees know where to look for schedule changes, venue updates, or joining instructions.
</Callout>

## Manage your events

After publishing, manage your events from the **My Events** area in MB Events. Each event includes actions for editing, deeper management, and deletion.

### Edit an event

Edit reopens the event wizard with your existing event details already filled in. Update the fields you need, then save to apply the changes.

This is the fastest option when you need to change timing, location details, visibility, or registration settings without rebuilding the event from scratch.

### Open the management page

Manage opens a fuller event management view for operational work after publishing. Use it when you need to work with registrations, schedules, ticket tiers, or other event settings beyond the quick edit flow.

If you are actively running an event, this is usually the place you return to most often.

### Delete an event

Delete opens a confirmation step before removing the event from active use. When you confirm deletion, ModelBoard marks the event as cancelled.

<Callout kind="alert" collapsed="false">
  Deleting an event cannot be undone. After deletion, the event status changes to cancelled rather than staying active.
</Callout>
