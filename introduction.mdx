## Streamlined Compliance

ModelBoard builds compliance into every layer of the platform so you can focus on creating without worrying about regulatory gaps. The system is designed around US 2257 record-keeping requirements and extends to broader verification needs across the adult entertainment industry.

### What you get

- **Identity and age verification** — Upload and store government-issued ID, model releases, and age verification records securely. Each record is tied to the collaborator profile and the project it belongs to.
- **Compliance roles per collaborator** — Assign On-Screen or Off-Screen roles to every collaborator so the platform knows who requires verification and who does not.
- **Project-level compliance tracking** — The Compliance tab inside each Collab project tracks which artifacts have been collected, which are pending, and which are missing before distribution.
- **Audit-ready records** — Every compliance artifact is stored with timestamps and contributor attribution so you can produce records on demand.

<Callout kind="info" collapsed="false">
  Compliance is not a separate billing tier — it is baked into the Collab project workflow. Every project has a Compliance tab from the moment it is created.
</Callout>

### Where compliance appears in the workflow

Compliance artifacts are referenced at multiple stages:

- **Production** — The Compliance tab lives alongside Overview, Collaborators, Schedule, Moodboard, and Screenplay.
- **Post-Production** — Project Files uploaded for review can be cross-referenced with compliance records.
- **Distribution** — File Sharing, Licensing, and Forensics all depend on compliance artifacts being in place before any asset leaves the project.

### How to get started

1. Complete your own profile verification by uploading required documents in your account settings.
2. When you create a Collab project and invite collaborators, assign each person a Compliance Role (On-Screen or Off-Screen).
3. Use the Compliance tab inside the project to track which collaborators have submitted their records.
4. Before moving any asset to Distribution, confirm that all required compliance artifacts are collected and approved.

<Callout kind="alert" collapsed="false">
  ModelBoard compliance tools help you organize and track records, but they do not constitute legal advice. Consult your own legal counsel to ensure your records meet all applicable regulatory requirements.
</Callout>

## Collaboration Tools

ModelBoard provides a structured collaboration workflow that takes a project from proposal through completion without scattering work across external tools. The Collabs system is the core of this experience.

### What you get

- **Proposals and invites** — Start a project from the Collabs hub at `/collabs`, invite collaborators by username or email, and assign roles and access scopes before anyone starts working.
- **Three-stage workflow** — Each project at `/collab/{id}` is organized into Production, Post-Production, and Distribution stages, each with dedicated tabs for the work that happens there.
- **Built-in communication** — Project Chat gives every collaborator a shared conversation space that is not tied to a single tab. Access is enabled automatically for all project members.
- **Asset management** — Exchange working files in Post-Production → Project Files, and manage delivery-ready assets in Distribution → File Sharing. Files carry version history, review statuses, and download audit trails.
- **Creative planning surfaces** — Moodboard, Screenplay, and Schedule tabs keep visual references, narrative structure, and timing aligned within the same project workspace.

### How the workflow stages connect

| Stage           | What happens here                         | Key tabs                                                             |
| --------------- | ----------------------------------------- | -------------------------------------------------------------------- |
| Production      | Planning, setup, and active coordination  | Overview, Collaborators, Compliance, Schedule, Moodboard, Screenplay |
| Post-Production | Working assets and service coordination   | Project Files, Pro Services                                          |
| Distribution    | Delivery preparation and downstream usage | File Sharing, Metadata, Credits, Licensing, Forensics & Distribution |

### How to get started

1. Go to the Collabs hub at `/collabs` and create a New Blank Project.
2. Use the Overview tab to describe the project goal, scope, and timing.
3. Invite collaborators from the Collaborators tab, choosing their Compliance Role and Access Scope.
4. Once collaborators accept, use the Production, Post-Production, and Distribution stages to coordinate the work.
5. Mark the project Completed when all deliverables are done and distribution is handled.

<Callout kind="tip" collapsed="false">
  The collaboration workflow supports various access levels — Viewer, Contributor, and Editor — so you can control who can view, upload, or manage different parts of the project.
</Callout>

## Professional Network

ModelBoard gives every creator and industry professional a verifiable presence on the platform. Profiles, portfolios, and connections are designed to build trust before a collaboration even begins.

### What you get

- **Verified profiles** — Complete identity verification so other professionals know you are a legitimate, compliance-checked member of the platform.
- **Portfolios** — Showcase your work with media, reviews, and industry credits. Portfolios are visible to collaborators and help you demonstrate your range and experience.
- **Creator profiles** — Dedicated profile pages for creators that highlight specialties, past projects, and availability for new work.
- **Connection-driven collaboration** — When you find someone you want to work with, initiate a Collab project directly. The proposal system handles invites, role assignment, and access scoping in one flow.
- **Organizational presence** — Businesses and studios get organization-level profiles with staff management, sub-accounts, and multi-studio oversight for enterprise operations.

### Account types and network access

| Account type    | Network capabilities                                                   |
| --------------- | ---------------------------------------------------------------------- |
| Model / Creator | Personal verified profile, portfolio, project participation            |
| Business        | Company profile, project creation, service provider visibility         |
| Studio          | Studio profile, model applications, casting calls, credits management  |
| Enterprise      | Multi-studio management, agency-level oversight, platform integrations |

### How to get started

1. Complete your profile with bio, specialties, and location details.
2. Upload verification documents to earn the verified badge.
3. Build your portfolio by adding media, credits, and project highlights.
4. Browse or search for other professionals when you are ready to collaborate.
5. Start a Collab project to turn a connection into a working relationship.

<Callout kind="info" collapsed="false">
  A complete, verified profile increases trust and response rates when you send collaboration proposals. Invest time in your portfolio before reaching out to new collaborators.
</Callout>
