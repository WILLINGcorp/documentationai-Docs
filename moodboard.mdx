## Purpose

The Moodboard tab keeps visual references, inspiration, and creative direction together inside the Collab project so owners and collaborators can align on the intended look and feel.

Use it to:

- Collect images, color palettes, typography samples, and texture references.
- Organize references into themes that communicate the visual direction.
- Add context explaining why each reference supports the project.
- Share and refine the creative direction with collaborators.

<Callout kind="info" collapsed="false">

Use the Moodboard to support the creative vision described in the [Overview](/overview). The Overview defines what the project is trying to achieve; the Moodboard shows how that direction should look and feel.

</Callout>

## When to update it

Update the Moodboard whenever the project's visual direction changes or collaborators need more context about a creative decision.

Typical moments to update:

- **During initial planning**: Add references that establish the intended visual language before creative work begins.
- **Before sharing the project**: Organize the references and add enough context for collaborators to understand the direction.
- **After feedback**: Remove references that no longer fit and add material that addresses open questions.
- **During production**: Update the board when the visual approach, palette, composition, or mood evolves.
- **Before final review**: Confirm that the board still reflects the direction the team is using.

## What to include

- **Visual references**
  Images, color palettes, typography samples, and texture references that represent the intended direction.
- **Themes**
  Logical groups such as lighting, color, composition, texture, and mood.
- **Annotation notes**
  Brief explanations of why a reference or cluster was selected and what the team should notice.
- **Creative decisions**
  References that clarify choices the team needs to make or apply consistently.

## Best practices

- **Keep the board focused**: Choose references that support the current creative direction instead of collecting everything that might be relevant.
- **Explain the reason for each reference**: A short note gives collaborators useful context that the image alone may not provide.
- **Organize for scanning**: Group related references so collaborators can understand the direction without reviewing every item individually.
- **Remove outdated material**: Delete or regroup references when they no longer represent the direction.
- **Review it together**: Use the Moodboard as a shared discussion point when collaborators provide feedback.

<Callout kind="tip">

Start with a small set of references that clearly establishes the direction. Add detail as the team makes decisions, rather than filling the board with unrelated inspiration.

</Callout>

## Workflow: keep your Moodboard useful

<Steps>
  <Step title="Gather initial references" icon="image" title-type="p">
    Collect images, color palettes, typography samples, and texture references that capture the intended visual direction. Choose material that helps collaborators understand the project's look and feel.

    Success looks like: the Moodboard gives the team a clear first impression of the visual direction without requiring additional explanation.
  </Step>

  <Step title="Organize references by theme" icon="image" title-type="p">
    Group references into logical clusters such as lighting, color, composition, texture, and mood. Use themes that match the decisions collaborators need to make.

    Success looks like: collaborators can find related references quickly and understand how the visual elements fit together.
  </Step>

  <Step title="Add annotation notes" icon="image" title-type="p">
    Write a brief note for each reference or cluster explaining why it was selected. Call out the specific qualities the team should use as guidance.

    Success looks like: each reference contributes a clear idea instead of leaving collaborators to guess what they should take from it.
  </Step>

  <Step title="Share the Moodboard with collaborators" icon="image" title-type="p">
    Notify the team that the Moodboard is ready and walk through the references together. Use the discussion to confirm that the visual direction supports the project described in the Overview.

    Success looks like: owners and collaborators share the same understanding of the intended look and feel.
  </Step>

  <Step title="Iterate based on feedback" icon="image" title-type="p">
    Remove references that no longer fit, add new material that resolves feedback, and reorganize the board as the direction evolves.

    Success looks like: the Moodboard reflects current decisions and remains useful throughout production.
  </Step>
</Steps>

## Role-specific guidance

<Tabs>
  <Tab title="Project owner (sender)" icon="user">

    As the sender, you establish the initial visual direction and keep the Moodboard aligned with the project's goals.

    - Gather and organize the first set of references before inviting collaborators.
    - Add notes that explain the creative intent behind important references.
    - Use feedback from collaborators to refine the direction without losing the project's original purpose.
    - Update the Moodboard when decisions change so it remains a reliable reference during production.

    Success looks like collaborators can understand the intended visual direction and contribute feedback without needing separate context.

  </Tab>

  <Tab title="Collaborator (receiver)" icon="users">

    As a receiver, you use the Moodboard to understand the visual direction and identify where your contribution should fit.

    - Review the references and annotation notes before contributing creative work.
    - Compare the Moodboard with the project's [Overview](/overview) to understand how visual decisions support the broader goal.
    - Share specific feedback about references, themes, and gaps in the direction.
    - Check the updated Moodboard when the project owner reorganizes or adds material.

    Success looks like your work and feedback reinforce the shared visual direction rather than introducing an unrelated look or feel.

  </Tab>
</Tabs>

## Common issues

<ExpandableGroup>
  <Expandable title="The Moodboard feels unfocused" default-open="false">

  **Cause:** The board contains too many references or includes material that does not support the current creative direction.

  **Fix:**

  - Remove references that do not inform a specific visual decision.
  - Group the remaining material by clear themes.
  - Add notes that explain the role of each important reference.
  - Compare the board with the creative vision in the [Overview](/overview).

  </Expandable>

  <Expandable title="Collaborators interpret a reference differently" default-open="false">

  **Cause:** The reference does not include enough context about the quality or decision it is meant to communicate.

  **Fix:**

  - Add an annotation explaining what collaborators should notice.
  - Identify whether the reference communicates lighting, color, composition, texture, mood, or another specific quality.
  - Discuss ambiguous references with the team and update the note after reaching alignment.

  </Expandable>

  <Expandable title="The Moodboard no longer matches the project direction" default-open="false">

  **Cause:** The visual direction changed, but the board still reflects earlier decisions.

  **Fix:**

  - Remove references that no longer fit.
  - Add material that represents the current direction.
  - Reorganize themes if the project's priorities changed.
  - Notify collaborators when the updated board affects their work.

  </Expandable>
</ExpandableGroup>
