<Update label="2026-06-03" description="v1.5.0" tags={["feature", "improvement", "security"]}>

## User-facing changes

- Added installable app support so you can launch ModelBoard from your device like a native app where supported.
- Opened mobile public navigation for visitors, making public pages easier to browse before signing in.
- Improved Studio signup and onboarding so new teams can choose the right account path and get oriented faster.
- Restored network discovery and public creator profile visibility so professionals can find creators and review public profiles again.

## Creator, compliance, and admin updates

- Updated creator solution cards and account guidance to make creator, business, studio, and enterprise positioning clearer.
- Improved vAulth compliance workflows with signature delegation and current signed release PDF downloads.
- Expanded admin tooling for user management, Pro membership changes, ambassador controls, moderation, and security-monitoring review.


</Update>

<Update label="2026-06-03" description="v1.4.0" tags={["feature", "improvement", "security"]}>

## New Features

- Added staff admin operations for user search, account type filtering, row-level support actions, Pro membership changes, ambassador toggles, and moderation workflows.
- Added OAuth client management guidance for allowed redirect origins in the SSO workspace.
- Restored public creator profile visibility so creator discovery can point viewers to profile pages again.

## Improvements

- Updated signup, onboarding, mobile access, and install guidance to match the current ModelBoard experience.
- Updated creator positioning across discovery and account documentation so creators, businesses, studios, and enterprise accounts are described consistently.
- Updated compliance guidance for vAulth signature delegation and current signed release PDF downloads.

## Security and Operations

- Documented how admins review security score, threat level, blocked requests, recommendations, and security audit logs where the monitoring dashboard is enabled.
- Clarified that detection threshold changes and threshold-change audit history are not exposed as completed admin workflows in the reviewed interface.

</Update>

<Update label="2024-11-15" description="v1.3.0" tags={["feature", "improvement"]}>

## New Features

- Added real-time collaboration invites for models and studios, streamlining content production workflows.
- Introduced universal 2257 compliance export directly from profile dashboards.
- New enterprise-level bulk user management for talent agencies.

## Improvements

- Enhanced professional networking search with advanced filters for account types (Model, Business, Studio, Enterprise).
- Optimized portfolio upload speeds by `>40%` for large media files.
- Updated UI for account type selection with preview cards.

## Bug Fixes

- Fixed casting application sync issues between studios and models.
- Resolved notification delays in collab workflow approvals.
- Corrected profile verification flow for business accounts.

</Update>
