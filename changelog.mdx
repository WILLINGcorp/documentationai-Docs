<Update label="2026-06-05" description="June 2026" tags={["feature", "improvement", "bugfix"]}>

## June 2026 release

### New Features

- Added installable ModelBoard app support so you can launch ModelBoard from supported browsers and devices.
- Added passkey setup during onboarding for faster, safer sign-ins.
- Added legal information and digital signature onboarding steps, with clearer guidance for [creator compliance](/creator-compliance).
- Published public Solutions pages and menu, plus improved public mobile navigation.

### Improvements

- Clarified account-specific onboarding copy so creators, businesses, studios, and [organizations](/organizations) see more relevant next steps.
- Improved Studio setup for profile details, organization information, and team preparation.
- Made onboarding dialogs scrollable on smaller screens.
- Clarified verification requirement messaging before restricted actions. Start with [getting started](/getting-started) for setup guidance.

### Bug Fixes

- Restored Studio profile access for authorized sub-accounts.

</Update>

<Update label="2024-11-15" description="v1.3.0" tags={["feature", "improvement"]}>

## New Features

- Added real-time collaboration invites for models and studios, streamlining content production workflows.
- Introduced universal 2257 compliance export directly from profile dashboards.
- New enterprise-level bulk user management for talent agencies.

## Improvements

- Enhanced professional networking search with advanced filters for account types (Model, Business, Studio, Enterprise).
- Optimized portfolio upload speeds by `>40%` for large media files.
- Updated UI for account type selection with preview cards.

## Bug Fixes

- Fixed casting application sync issues between studios and models.
- Resolved notification delays in collab workflow approvals.
- Corrected profile verification flow for business accounts.

</Update>

<Update label="2024-10-20" description="v1.2.0" tags={["feature", "bugfix"]}>

## New Features

- Profile portfolios now support embedded video previews from major platforms.
- Added review and rating system for business-service collaborations.
- Integrated webhook support for custom notifications: `https://your-webhook-url.com/webhook`.

## Improvements

- Streamlined compliance verification logic for platform-agnostic 2257 records.
- Better mobile responsiveness for networking feeds.

## Bug Fixes

- Fixed enterprise dashboard access for multi-studio holdings.
- Patched credential exposure in shared collab links.
- Resolved search indexing delays for new profiles.

</Update>
