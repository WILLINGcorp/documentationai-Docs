### Administration controls

<Update label="2026" description="Administration controls" tags={["feature", "security", "improvement"]}>

#### Organization administration

- Organization owners can now adjust staff sub-account capabilities from an editable capability matrix. Owners keep full access, while staff see a read-only view of what their role allows.
- Owners can control which staff members may manage profile, billing, content, storage, messaging, and collaboration actions without removing them from the workspace.

#### Admin security and OAuth

- Admins now have a Security Monitoring area for reviewing account risk, session health, blocked activity, and alerts that need attention.
- OAuth client management now helps admins control approved callback origins, scopes, client status, and credentials from the admin experience.

</Update>

### Account and privacy safeguards

<Update label="2026" description="Account and privacy safeguards" tags={["security", "improvement"]}>

#### Authentication hardening

- Passkey sign-in now supports both email-bound and discoverable passkeys. Accounts with enough registered passkeys and downloaded backup codes can enforce passkey-only authentication.
- Enforced accounts keep recovery paths through email one-time passcodes and single-use backup codes.
- Sign-in and password reset flows now use generic messages that avoid confirming whether an email address exists.
- Authentication attempts are rate-limited, with countdown guidance when a user needs to wait before trying again.
- Auth redirects now use safe, approved application origins so confirmation and reset links do not send users to untrusted callback domains.

#### Event and portfolio privacy

- Event attendee lists now show confirmed attendees only, and attendee check-in status is visible only to event organizers.
- Portfolio privacy controls now better protect public views, including blurred pending-moderation items, per-field profile visibility controls, and shared portfolio links scoped to the selected items or album.

</Update>

### Collaboration and positioning updates

<Update label="2026" description="Collaboration and positioning updates" tags={["improvement", "fix"]}>

#### Release-form download reliability

- Collaboration asset downloads now stay locked until the required release form is signed, making the restriction clear before a user attempts to download.
- Asset cards now show video processing status so collaborators can tell when a file is still encoding and when it is ready to stream or download.
- Versioned release assets help teams identify the correct revision before sharing or downloading content.

#### Public solutions pages

- Public solutions pages now use current role-based positioning for creators, studios, talent agencies, creator platforms, video editors, and award shows.
- The solutions experience now highlights audience-specific workflows, proof points, FAQs, pricing paths, and clearer calls to action for each visitor segment.

</Update>
