<Update label="2026-07-22" description="v2.0.0" tags={["feature", "improvement", "bugfix"]}>

## New Features

- GRABBYS OAuth users now see a dedicated account type selection screen before onboarding, allowing them to choose Content Creator, Business, or Studio. Selecting Enterprise opens a waitlist form.
- Admins can now manage OAuth allowed origins through a dedicated admin page, supporting both exact URLs and regex patterns with enable/disable toggles. Changes propagate within approximately 30 seconds.
- Security audit events are now logged for authentication failures, rate-limit triggers, passkey errors, and rejected OAuth origins. All sensitive data is hashed and the log is admin-only.

## Improvements

- Redesigned the sign-in and sign-up page with a split-panel layout, updated brand messaging, and expanded form space for account type selection.

## Bug Fixes

- Fixed an issue where collaborator avatars and display names were not loading in project chat, proposals, asset comments, and file permissions dialogs.



</Update>

<Update label="2024-11-15" description="v1.3.0" tags={["feature", "improvement"]}>

## New Features

- Added real-time collaboration invites for models and studios, streamlining content production workflows.
- Introduced universal 2257 compliance export directly from profile dashboards.
- New enterprise-level bulk user management for talent agencies.

## Improvements

- Enhanced professional networking search with advanced filters for account types (Model, Business, Studio, Enterprise).
- Optimized portfolio upload speeds by `>40%` for large media files.
- Updated UI for account type selection with preview cards.

## Bug Fixes

- Fixed casting application sync issues between studios and models.
- Resolved notification delays in collab workflow approvals.
- Corrected profile verification flow for business accounts.




</Update>
