<Update label="2026-10-19" description="v0.42.0" tags={["New Features"]}>
  ### This latest update of the ModelBoard Platform introduces the Blog Publishing system for creating, optimizing, translating, and publishing blog content.

  ## New Features

  ✅ **NEW** Blog Publishing system with a full-featured post editor in the admin Content Hub.

  ✅ **NEW** Rich-text editor with formatting, slash commands, desktop and mobile preview, word count, and estimated reading time.

  ✅ **NEW** Global slug management with slugs unique across all languages and locales, automatic generation from titles, and manual editing with normalization. Normalized slugs use lowercase characters, no accents, hyphens, and a maximum length of 120 characters.

  ✅ **NEW** SEO panel with meta title, meta description, canonical URL, Open Graph image, noindex toggle, live search preview, and content diagnostics.

  ✅ **NEW** Tag system with autocomplete suggestions, automatic lowercasing, and deduplication.

  ✅ **NEW** Byline author management for creating reusable author profiles with a name, photo, bilingual bios, and social links.

  ✅ **NEW** Bilingual support for English and French posts with localized category labels.

  ✅ **NEW** Translation draft creation that copies a post into the other language as a starting draft.

  ✅ **NEW** Six blog categories: Announcements, Events, Partnerships, New Features, Guides & Tutorials, and Industry Insights.

  ✅ **NEW** Publishing workflow with Draft, Published, and Scheduled statuses.

  ✅ **NEW** Scheduled publication with timezone selection and future-time validation.

  ✅ **NEW** Autosave for existing draft posts every 30 seconds.

  ✅ **NEW** Featured post control for published posts.

  ✅ **NEW** Revision history with up to 50 retained revisions.

  ✅ **NEW** Cover image upload with 16:9 crop, zoom, and required alt text.

  ✅ **NEW** Photo gallery supporting up to 20 images with optional captions.

  ✅ **NEW** Public RSS feed and sitemap for published blog posts with localized metadata and canonical URL filtering.
</Update>

<Update label="2026-09-19" description="v0.41.0" tags={["New Features"]}>
  ### This latest update of the ModelBoard Platform introduces the Model Release Builder for creating structured model release documents.

  ## New Features

  ✅ **NEW** Model Release Builder: Create structured model release documents from a collaboration's Compliance tab or a production's compliance page.

  ✅ **NEW** Four business model presets: Shared Ownership + Indie Licensing, Revenue Share, Paid Performance + Full Transfer, and Limited License.

  ✅ **NEW** Guided release creation wizard with four steps: Business Model, Parties, Jurisdictions, and Clauses.

  ✅ **NEW** "My model releases" page listing all releases where you are a party or author, with status filtering.

  ✅ **NEW** Release editing canvas with clause library, document assembly, and clause inspector.

  ✅ **NEW** Jurisdiction packs with governing law selection, including Québec bilingual notices and EU/UK removal procedure requirements.

  ✅ **NEW** Document preview with signer locale selection.

  ✅ **NEW** Validation engine with blocking errors, warnings, suggestions, and coverage checks.

  ✅ **NEW** "TEST - NOT BINDING" watermark for releases containing clauses not yet approved by counsel.

  ✅ **NEW** Release statuses: Draft, In review, Signing, Executing, Executed, Amended, Terminated, Expired, Voided.
</Update>
