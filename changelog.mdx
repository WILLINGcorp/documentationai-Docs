<Update label="2026-07-08" description="v1.4.0" tags={["feature"]}>

## New Features

- Introduced real-time attendee chat for MB Events with channel-based messaging, @-mentions, message editing, and soft-delete.
- Added standard and announcement channel types so organizers can control whether attendees can reply or only read updates.
- Added direct messaging and user blocking from within event chat, with automatic message filtering and notification suppression for blocked users.
- Added a content reporting system with standard and legal-floor report categories. Legal-floor reports are escalated to Platform Admin and cannot be dismissed by organizers.
- Added organizer moderation tools: message removal, user removal from event channels, and a reports queue with open and closed views.
- Added chat notifications for mentions, announcements, and direct messages, with per-channel mute controls.
- Added presence indicators (online status and typing indicators) for active channel participants.
- Added automated chat lifecycle management: scheduled, open, closed, and purged states with configurable pre-event open time and closure notice schedule.

## Improvements

- Chat closes automatically 30 days after an event ends and messages are purged after 60 days. Purging is skipped when active legal-flagged reports exist.
- Unread message tracking with channel badges, in-channel "New" divider, and automatic mark-as-read.
- Messages support a 4,000 character limit with a live counter, optimistic sending with retry on failure, and a 15-minute edit window.




</Update>
